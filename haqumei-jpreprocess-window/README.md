# haqumei-jpreprocess-window

The utility library for [haqumei-jpreprocess](https://crates.io/crates/haqumei-jpreprocess),
Japanese text preprocessor for Text-to-Speech application.

This package implements mutable window.

This project is a rewrite of [OpenJTalk](http://open-jtalk.sourceforge.net/) in Rust language.

## Usage

Put the following in Cargo.toml

```toml
[dependencies]
haqumei-jpreprocess-window = "0.1.0"
```
